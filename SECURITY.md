# Seguridad / Security

## Español

Si encuentra una vulnerabilidad, no abra un issue público. Escriba a [asteins@gmail.com](mailto:asteins@gmail.com) con los detalles y los pasos para reproducirla.

El sitio es estático: no tiene servidor, cuentas de usuario ni datos personales. Lo único que guarda es el tono elegido para cada tema, en el navegador de cada persona.

Para reducir el riesgo de dependencias comprometidas, pnpm rechaza versiones con menos de 3 días de publicadas y bloquea los scripts de instalación. Las GitHub Actions están fijadas por SHA de commit.

## English

If you find a vulnerability, please don't open a public issue. Write to [asteins@gmail.com](mailto:asteins@gmail.com) with the details and steps to reproduce it.

The site is static: it has no server, user accounts or personal data. The only thing it stores is the key chosen for each song, in each person's browser.

To reduce the risk of compromised dependencies, pnpm rejects versions published less than 3 days ago and blocks install scripts. GitHub Actions are pinned by commit SHA.
