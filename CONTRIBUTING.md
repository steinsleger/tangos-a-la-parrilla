# Cómo colaborar / Contributing

[Español](#español) · [English](#english)

## Español

Para reportar errores o pedir temas no hace falta programar: use los [formularios de GitHub](https://github.com/steinsleger/tangos-a-la-parrilla/issues/new/choose) o escriba a [asteins@gmail.com](mailto:asteins@gmail.com).

Para colaborar con código:

1. Siga los pasos de [Uso local](README.md#uso-local).
2. Haga cambios pequeños y enfocados. Si es algo grande, abra primero un issue para conversarlo.
3. Ejecute `pnpm test` y `pnpm build` antes de abrir el pull request.
4. Agregue los cambios visibles para los usuarios a [CHANGELOG.md](CHANGELOG.md).

Las convenciones del proyecto están en [AGENTS.md](AGENTS.md). Al contribuir, usted acepta que su aporte se publique bajo la misma [licencia](LICENSE) del proyecto.

## English

You don't need to code to report a bug or request a song: use the [GitHub forms](https://github.com/steinsleger/tangos-a-la-parrilla/issues/new/choose) or write to [asteins@gmail.com](mailto:asteins@gmail.com).

To contribute code:

1. Follow the steps in [Running it locally](README.md#running-it-locally).
2. Keep changes small and focused. For anything large, open an issue first to discuss it.
3. Run `pnpm test` and `pnpm build` before opening a pull request.
4. Add user-facing changes to [CHANGELOG.md](CHANGELOG.md).

The project's conventions are in [AGENTS.md](AGENTS.md). By contributing, you agree that your work is published under the project's [license](LICENSE).
